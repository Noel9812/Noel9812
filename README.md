## 🚀 Featured Projects

### **🍕 Gitzzeria - Full-Stack Canteen Management Platform**
A comprehensive cashless canteen solution built with **React, TypeScript, and Firebase** that revolutionizes campus dining through digital transformation.

#### **Key Features:**
- **Complete Full-Stack Implementation:** React frontend with Firebase backend (Firestore, Auth, Storage)
- **Real-Time Operations:** Live order tracking, queue management, and instant notifications
- **Secure Payments:** Integrated Razorpay API with UPI, cards, and wallet support
- **Admin Dashboard:** Complete CRUD operations, analytics, and user management
- **Responsive Design:** Mobile-first interface built with Tailwind CSS
- **Role-Based Access:** Separate interfaces for students, faculty, and administrators

#### **Tech Stack:** React · TypeScript · Firebase · Tailwind CSS · Node.js · Razorpay API

### **🛡️ RNIDS - Real-time Network Intrusion Detection System**
A **Python Flask** backend application with machine learning integration, featuring a full dashboard interface for security monitoring.

#### **Key Features:**
- **Full Dashboard Interface:** Interactive admin panel with real-time data visualization
- **RESTful API Architecture:** Python Flask backend serving ML predictions to web interface
- **Real-Time Monitoring:** Live threat detection with Firebase integration for persistent storage
- **Responsive Frontend:** Bootstrap-based dashboard with interactive charts and graphs
- **Data Processing Pipeline:** From packet capture to actionable security insights

#### **Tech Stack:** Python · Flask · Firebase · Scikit-learn · Bootstrap · REST APIs
